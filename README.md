
# Graphic Designer Portfolio

## About the Project

This is my personal portfolio website where I showcase my work as a graphic designer. I created this website to display my designs, introduce myself, share my services and provide a way for people to contact me.

I wanted to keep the design simple, clean and modern, with a focus on my graphic design works.

## Pages

- **Portfolio** - Introduction and information about me.
- **Services** - Different graphic design services I offer.
- **Experience** - My experience and background.
- **Projects** - A gallery where I showcase my graphic design works.

## Technologies Used

- HTML5
- CSS3

## What I Learned

While working on this project, I learned more about:

- Creating and structuring webpages using HTML.
- Styling webpages using CSS.
- Using CSS Grid to arrange images in rows and columns.
- Working with image sizes, spacing and alignment.
- Creating navigation links between different pages.
- Using hover effects and improving the overall appearance of a website.
- Finding and fixing HTML and CSS errors.

This project also helped me understand how small CSS changes can affect the overall layout of a website.

## AI Usage

I used ChatGPT during this project mainly to clarify doubts and understand certain parts of HTML and CSS.

I took help with some CSS properties, fixing layout issues, image alignment and spacing. I also used it to understand how certain styling techniques work.

The project design, structure and implementation were done by me while learning and experimenting with the code.


## Contact Form

The contact form on the website is currently only for design purposes. Users can enter their name, email, subject and message, but the form does not actually send emails or store any messages.

I haven't connected any backend or email service to it yet. I might add this functionality in the future.


## Social Media Links

The Instagram, Facebook, X (Twitter) and LinkedIn icons in the footer are clickable and redirect to their respective social media websites.

However, they are not linked to my personal accounts yet. They currently use general platform links as placeholders. I may connect my actual profiles in the future.


## Note

Since this is a public repository, I haven't added a working contact form or connected my personal social media accounts. I also wanted to avoid receiving random or unwanted emails through the portfolio.

These features may be updated in future versions of the project.



## Running the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. You can also use the Live Server extension in VS Code.
